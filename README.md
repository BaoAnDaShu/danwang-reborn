# 🛵 40岁 · 单王重生（放置经营版）

一个浏览器里直接玩的放置经营小游戏：40 岁被裁码农重生送外卖，用算法思维规划路线，
从见习骑手一路干到**城市单王**，再当**站长**、开**电动车店**、做**换电网络**，攒钱买房买车。

纯静态单文件网页，无需服务器、无需联网、不依赖任何后端。进度自动保存在浏览器本地。

## 玩法
- 跟着顶部**主线剧情**跑单升级，派单调度交给骑手团队自动完成
- 升级装备与技术（电瓶、路径算法、口碑）、招募骑手、点技能树
- 触发角色剧情线：☕ 苏晴（女主）、👨‍🦲 老王、🏍️ 飞哥、🧔 老赵、👵 妈妈……
- 商业与资产：开店、换电柜、买房买车，全部产生被动收入
- 关掉页面也有**离线收益**（按 50% 结算，最多 2 小时）

## 本地运行
直接用浏览器打开 `index.html` 即可（会自动跳到 `单王重生-放置版.html`）。
或在该目录起一个本地服务：

```bash
python -m http.server 8123 --bind 127.0.0.1
# 浏览器访问 http://127.0.0.1:8123/
```

## 文件说明
- `index.html` —— 入口（重定向到放置版）
- `单王重生-放置版.html` —— 游戏本体（放置经营版，推荐）
- `单王重生.html` —— 早期动作跑单版（手动骑电动车送餐）

## 部署到 GitHub Pages
1. 在 GitHub 新建仓库（例如 `danwang-reborn`），把本目录内容推上去
2. 仓库 Settings → Pages → Source 选 **Deploy from a branch** → 分支 `main` / 目录 `/ (root)`
3. 稍等一两分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`

> 本机公钥未注册到 GitHub 时，推送会报 `Permission denied (publickey)`，
> 需在 GitHub → Settings → SSH and GPG keys 添加本机 `~/.ssh/id_ed25519.pub`。
